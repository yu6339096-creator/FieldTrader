## 主要功能

| 模块 | 功能 |
| --- | --- |
| 听声识物 | 持续监听 Windows 输出音频，以拿起声为重点，与本地模板匹配 |
| 游戏悬浮窗 | 置顶、拖动、锁定、透明度、极简模式；保留最近两轮有效结果 |
| 候选物品 | 同声组显示多个物品，按占格数与横竖摆放筛选 |
| 本地数据库 | JSON、图片和 WAV 文件；支持物品及声音样本管理 |
| 游戏语音板 | 中文文字朗读、自定义 WAV、8 段内置录音与中文用途备注 |
| 真人麦克风混音 | 真人说话与音效同时送入虚拟线路，独立音量和发送电平 |
| 自动按键说话 | 音效触发后等待组合键松开，自动按住 T，结束后松开；支持自由麦 |
| 发送增强 | 麦克风音量最高 400%，发送增强 ×1～×8，带输出峰值保护 |

当前内置 **109 个物品、24 个声音组、389 段声音样本**，其中 107 件有图片、2 件待补图；运行时生成 113 份匹配模板。

## 快速开始：听声识物

1. 主界面选择游戏实际使用的**声音输出设备**。
2. 点击 **开始监听**，游戏悬浮窗会自动打开。
3. 在游戏里拖动物品，查看候选图片、名称、相似度与识别状态。
4. 同声物品可通过 1 格、2 格横/竖、4 格、6 格横/竖等规格缩小候选范围。

识别重点为拿起声，不要求存在后半段放下声。主窗口最小化或悬浮窗隐藏后仍会监听，点击停止才停止，退出主程序会释放设备。

**相似度门槛为 70%，它不是识别准确率。** 声音相近的物品会合并显示候选；未确定时明确提示，并在悬浮窗保留上次有效结果。枪声、人声和环境声仍可能影响匹配。

悬浮窗优先支持窗口化、无边框全屏；普通 Topmost 不能保证覆盖所有独占全屏游戏。

## 快速开始：让队友听到真人声和音效

| 位置 | 选什么 |
| --- | --- |
| 软件 → 真人麦克风 | **实体麦克风/耳麦**，不能选 CABLE Output |
| 软件 → 混音送到 | **CABLE Input** |
| 软件 → 操作 | 点击 **开启麦克风混音** |
| 游戏 → 麦克风 | **CABLE Output** |
| 游戏 → 声音输出 | 仍使用自己的耳机 |

按卡片上的快捷键播放音效；内置录音默认 `Ctrl+Shift+1～8`，文字朗读默认 `Ctrl+Alt+1～8`，可以自行修改。

- 按键说话默认 **T**。触发音效后松开组合键，软件会在游戏前台自动按住说话键播放，结束后松开。
- 真人说话仍沿用游戏的按键说话或自由麦设置；切换成自由说话时，软件播放音效不模拟说话键。
- 可从**麦克风 200%、发送增强 ×2**开始调整；音效音量、麦克风音量和发送增强实时生效。
- 看清“仅本地试听”与“发送至游戏”：本地试听不等于队友已经收到声音。
- 隐藏语音窗口仍会继续混音；关闭混音或退出软件才停止转发。下一次启动需手动开启混音。

更多步骤与排查方法见 **[使用说明](docs/USAGE.md)**。

## 数据与备份

个人数据目录：`%LOCALAPPDATA%\FieldTrader`。备份时退出软件，复制整个文件夹。

源码自带的 `SeedData` 是初始物品库，`VoiceSeed` 是语音板内置音效，`ThirdParty` 是完整原始 VB-CABLE 组件。后续添加物品请使用软件中的数据库入口，并保留同声组及占格信息。

## 开发者入口

项目使用 C# / .NET 8 / WPF / NAudio 2.2.1。源码、数据库和可重用的打包脚本均在此仓库。

```powershell
# 需要 .NET 8 SDK
./build.ps1

# 同时生成安装包，需要 Inno Setup 6
./build.ps1 -CreateInstaller
```

构建结果位于 `artifacts/publish` 与 `artifacts/installer`，分层结构和验证方法见 [开发文档](docs/DEVELOPMENT.md)。
