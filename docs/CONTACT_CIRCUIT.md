# 0.8.17 联络人串联兑换

从“自动买入/联络人兑换”进入，操作选择“联络人串联：按勾选清单兑换/补齐”。勾选商品，填写整轮游戏币支出上限和最多兑换份数，勾选启用并开始，4秒内切回游戏大厅、联络人或商店页面。启动器继续默认请求管理员权限。无需逐笔人工确认。

| 迪克 | 03、M4、926高级野战胸挂、H-Tac A8/A9、SH12；限时目录12项已登记装备/手雷/弹药白名单 |
| 兰德尔 | DK8军用防弹面罩、GS2战术耳机 |

没有登记兑换目标的另外三位联络人跳过。926已有历史详情识别数据，实时配方依然重新读取。限时物品只处理白名单；常规目录不会买限时白名单以外的商品。

每个勾选目标每批最多兑换一份配方。手雷、弹药按卡片xN核对产出数量；面罩、100D等无限兑换商品也不会无限循环。有限次数/冷却/售罄跳过，完整列表找不到的目标记录为跳过。03记录12小时、GS2记录5小时冷却，其他商品以当前卡片状态为准。

限时物品先检查当前批，再在开启刷新且按钮可用时最多刷新一次并处理新批。刷新会消耗机会，刷新结果未核实不再刷新。只有限时目录执行此逻辑；头盔和甲的独立冷却不受它影响。冷却时不驻留等待，也不自动启动下一轮。

合计价格是整套材料价值，补齐价格是本次游戏币支出。仓库材料已齐时支出记0并点击兑换。持有材料仍计入经济成本。926、A8、A9需用户设置已核实手续费/管理费，预计净利润及利润率达标才兑换；费用未知时跳过。其他勾选必换目标按预算处理。

每次导航和交易都重新截图定位OCR文字；不使用旧截图坐标。提交前复核配方、金额与剩余整轮预算，出现报价变化停止重新评估。补齐后的固定文案和目标名称相符时自动确定。窗口切走、全局急停、关闭开关或错误页面停止；未知结果不重试。本轮结束重置运行状态，历史未知记录不锁住下一次主动开始。

兑换详情遮挡仓库，因此串联模式在打开详情前保存无遮挡的仓库基线。完成后核对同一仓库视口新增目标（OCR，或同一物品模型及弹药数量），再用独立新帧复核。成品不在可见仓库区域、名称缺失或视口变化时会停止，不能仅凭点击或弹窗关闭记成功。此时先检查游戏，再主动运行下一轮。成品参考价和支出报价不冒充实际扣款。

数据在 `%LOCALAPPDATA%/FieldTrader/market/real-execution`：`contact-circuit-settings.json` 保存勾选/筛选；`contacts-*/summary.json` 和 `events.jsonl` 是整轮记录；截图在 `screens`；原始识别输出在证据目录；`native-input-events.jsonl` 记录鼠标请求与返回；`contact-exchanges.jsonl` 只记核实成功。测试账本用 `test-` 前缀，与真实账本隔离。

验证命令：MarketReplay 的 `--contact-circuit-check <输出目录>`、`--contact-circuit-stored <历史输出目录> <输出目录>`、原有 `--auto-buy-check`。合成状态机、历史真实YOLO/OCR结果回归都不等同于新版真实游戏整轮测试；打包过程不启动游戏交易。出售模块未加入本轮。
