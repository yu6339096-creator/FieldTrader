# OCR为主的导航

文字目标默认使用当前帧高置信度OCR的精确名称、限定区域和上下文定位，点击文字框中心。YOLO和已标定布局作为辅助证据；滚动视口、数量加减等无文字目标仍使用原有定位方式。需要旧严格视觉关联的调用可设置TargetQuery.PreferOcr=false。

重复文字不会任取一个。点击前仍核对窗口、画面时间、目标文字及坐标；OCR目标不再因辅助YOLO框轻微抖动或漏检而失效。文字移动仍需重新定位。

每次任务拥有独立OcrNavigationContext。输入适配器返回后记录上一步意图；新画面被分类为Unknown时，以该步预期页面和当前多个独立OCR特征核实位置。仅有点击记录无法恢复页面；错误、确认弹窗、窗口变化、旧帧、超过30秒的上下文均拒绝恢复。不会用点击记录覆盖已识别出的相反页面。

NavigationEvidenceLog新增inputs.jsonl，记录Attempted、AdapterReturned状态、目标文字、文字框、物理坐标、预期前后页面、帧ID及图像哈希。输入返回不代表成功；verification.jsonl单独记录新画面核验结果。暂停、取消和急停机制保留。

当前文字恢复支持Market、Purchase、Exchange、ContactShop及Warehouse，且只在相应文字证据充分时生效。并非所有游戏页面均已支持。菜单、联系人、分类、商品名称和取消/关闭等文字定位走新路径。

通用导航队列仍不提交购买、兑换、确定、补齐或消耗刷新机会。真实游戏输入限制没有放宽。本轮81项导航回归通过，其中6项新增OCR与点击上下文检查；测试使用程序夹具，不是实机自动交易验收。Release编译0警告0错误。
